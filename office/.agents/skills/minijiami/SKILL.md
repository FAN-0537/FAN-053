# 数字转中文大写金额

## 规则

1. 只处理非负金额，最多两位小数。
2. 使用“元、角、分”和“零、壹、贰、叁、肆、伍、陆、柒、捌、玖”。
3. 连续零只保留一个“零”，末尾零省略。
4. 整数部分按“万、亿”分组。

## 示例

| 输入 | 输出 |
| --- | --- |
| 0 | 零元整 |
| 1234.56 | 壹仟贰佰叁拾肆元伍角陆分 |
| 10010 | 壹万零壹拾元整 |

## 输出要求

只返回大写金额，不附加解释；无法解析时返回错误说明。
